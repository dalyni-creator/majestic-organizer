# История изменений

## 9.4.1

- Добавлен переключатель сканирования: один канал для меньшей нагрузки или до двух каналов для более быстрой обработки. Выбор сохраняется между запусками. На системе с одним логическим процессором остаётся один канал.
- Папки Steam `thumbnails` исключены на любой глубине, независимо от регистра имени. Их файлы также пропускаются при выборе отдельных изображений.
- Перед «Начать заново» добавлена иконка круговой стрелки.
- Настройка каналов блокируется во время распределения и загрузки обновления.
- Алгоритм OCR, языковые модели и проверка целостности файлов не изменены.

Проверки: 47 автоматических тестов и GUI на Linux. Windows-сборка и запуск проверяются отдельно в GitHub Actions.

## 9.4.0

- Один OCR-процесс по умолчанию и пониженный приоритет Windows.
- Улучшено распознавание дежурств с телефоном независимо от обоев.
- Проверка обновлений через GitHub Releases, установка с согласия пользователя.
