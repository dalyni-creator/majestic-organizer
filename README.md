# Majestic EMS Organizer

**Программа для Windows, которая распределяет скриншоты Majestic RP по папкам.**

Выберите папку или отдельные изображения, нажмите **«Распределить»** — программа прочитает текст на скриншотах и сохранит их в соответствующие категории.

[**Скачать последнюю версию**](https://github.com/dalyni-creator/majestic-organizer/releases/latest)

## Установка

1. Откройте страницу последней версии по ссылке выше.
2. В разделе **Assets** скачайте файл `MajesticOrganizer-Setup-…-x64.exe`.
3. Запустите установщик и следуйте его шагам. При желании добавьте ярлык на рабочий стол и в меню «Пуск».
4. Откройте Majestic Organizer.

**Python и отдельная установка Tesseract не нужны** — всё необходимое включено в установщик.

Скачивайте именно установщик `.exe`. Файл `update.json` нужен самой программе, а архивы **Source code** на странице выпуска не являются готовым приложением.

**Поддерживаемая система:** Windows 10 версии 1809 и новее или Windows 11, 64 бита. Распознавание использует процессор; специальная видеокарта и CUDA не требуются.

## Как распределить скриншоты

1. Нажмите **иконку папки**, чтобы выбрать папку со скриншотами, или **иконку файла**, чтобы выбрать отдельные изображения.
2. Выберите, нужно ли **оставлять оригиналы**.
3. Стрелками выберите режим: **«По дням»**, **«По неделям»** или **«Без даты»**.
4. Нажмите **«Распределить»**.
5. Дождитесь завершения. Шкала показывает прогресс, карточки — количество успешно сохранённых файлов в каждой категории.

Последний выбранный путь или список файлов сохраняется между запусками.

## Настройки

Нажмите **шестерёнку рядом со статусом** в правом верхнем углу. Стрелками выберите режим:

- **Слабый ПК** — один канал, меньше нагрузка. Режим по умолчанию.
- **Быстро** — до двух изображений одновременно. На системе с одним логическим процессором остаётся один канал.

В этом же меню можно включить или выключить **звук по завершении**. При остановке кнопкой ■ сигнал не воспроизводится. Выбор сохраняется между запусками. Настройки недоступны во время распределения.

Подсказка «Копировать вместо перемещения» появляется при наведении на **«Оставлять оригиналы»**.

Алгоритм OCR и проверка целостности одинаковы в обоих режимах. Папки Steam **`thumbnails`** автоматически пропускаются на любой глубине, в том числе при выборе отдельных файлов.

## Категории

| Папка | Что программа ищет на скриншоте |
| --- | --- |
| Таблетки | Уведомление «Вы вылечили…» |
| Вакцины | Уведомление «Вы вакцинировали…» |
| ПМП | Уведомление «Вы реанимировали…» |
| Мед.справки | Уведомление о выдаче медицинской справки, в том числе о физическом или психическом здоровье |
| Дежурства | Игровой телефон в правой нижней части экрана; распознавание опирается на элементы интерфейса и текст, а не на обои |
| Документы | Документ со Static ID или номером документа |
| Госволна | Уведомление «Ваше объявление одобрено» |
| Нераспознанное | Изображения, для которых не удалось уверенно определить категорию |

Результат зависит от читаемости текста, масштаба и игрового интерфейса. В сомнительных случаях проверьте папку **«Нераспознанное»**. Для первого распределения рекомендуем оставить оригиналы.

## Где искать результат

Отдельную выходную папку выбирать не нужно.

- **Выбрана папка:** категории создаются внутри неё.
- **Выбраны отдельные файлы:** каждый результат сохраняется рядом со своим исходным файлом.

Например, при режиме **«Без даты»**: `Скриншоты/Вакцины/снимок.jpg`

При режиме **«По дням»**: `Скриншоты/2026-11-12/Вакцины/снимок.jpg`

При режиме **«По неделям»** категории объединяются в папки недель с понедельника по воскресенье.

**Дата берётся из метаданных изображения (EXIF), а если её там нет — из времени изменения файла. Дата на игровом экране не считывается для группировки.** Пересылка файлов и распаковка архивов могут изменить время изменения.

## Оригиналы и повторное распределение

**«Оставлять оригиналы» включено:** программа создаёт копии, исходные скриншоты остаются на месте.

**Выключено:** программа переносит изображения. Перед удалением исходника проверяется целостность записанной копии.

Совпадающие имена не приводят к перезаписи: новый файл получает номер. Если изображение не удалось прочитать или записать, исходный файл остаётся на месте.

Готовые папки категорий исключены из повторного сканирования. Обычные подпапки выбранной папки просматриваются.

**Если оригиналы сохранены, повторное распределение тех же исходников создаст дополнительные копии.** Кнопка «Начать заново» не отменяет результат предыдущего запуска.

## Остановка

Во время работы появляется квадратная кнопка **■**. Нажмите её, чтобы остановить распределение.

На плашке ненадолго появится **«Распределение прекращено»**. Уже созданные файлы останутся в своих папках, оставшиеся исходники не будут перенесены. Завершение уже запущенного распознавания может занять некоторое время.

После окончания кнопка меняется на **«Начать заново»** с иконкой круговой стрелки и сохраняет это название до изменения выбранного пути или списка файлов.

## Скорость и нагрузка

Изображения обрабатываются **локально** с помощью Tesseract с русской и английской языковыми моделями.

По умолчанию используется один процесс распознавания с пониженным приоритетом Windows. Это уменьшает конкуренцию с другими приложениями, но большая очередь всё равно может обрабатываться долго.

Результаты распознавания неизменённых изображений сохраняются в локальном кэше и ускоряют повторную обработку. Кэш не содержит самих скриншотов.

## Обновления

При запуске программа проверяет наличие новой версии в этом репозитории. Если обновление доступно, она предлагает установить его.

Загрузка начинается с согласия пользователя. Перед запуском установщика проверяются размер и контрольная сумма файла. Без подключения к интернету сортировка продолжает работать.

Пользователям версий **до 9.4.0** нужно один раз вручную установить актуальную версию — в старых выпусках проверки обновлений нет.

## Окно и удаление

Окно можно перемещать за верхнюю панель и менять его размер за края или углы. Карточки перестраиваются под размер окна.

Для удаления откройте **Параметры Windows → Приложения**, найдите **Majestic Organizer** и выберите **«Удалить»**.
